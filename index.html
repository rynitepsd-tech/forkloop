Forkloop

Turn your agent's failures into verified training data.

When a computer-use agent fails a workflow in real software, Forkloop restores an earlier checkpoint of the world and the agent's memory, lets a teacher try again on independent copies, keeps only the paths the application's database confirms, and exports them with full lineage. Then it tests the retrained agent alone, on tasks it has never seen.

The loop

1

Record

Your agent attempts real workflows. Checkpoints bind the world (VM snapshot or deterministic replay) to the agent's explicit memory and history.

2

Find restart points

From evidence only: the first near-miss of a required value, the first damaged checkpoint, the start of a loop, or step 0.

3

Repair

A teacher continues from each restored checkpoint on k independent copies. It sees what the agent saw, and is never told why the attempt failed.

4

Verify

SQL checks on the applications' databases: right record, right value, no duplicate, no collateral edit. No model judges.

5

Export

Immutable datasets with sha256 lineage to every source trajectory, preference pairs, and audits of what each input contained.

6

Evaluate alone

The retrained agent runs held-out tasks with no teacher and no search. Unscored infrastructure failures are reported, never counted as passes or failures.

Try it without an account

The offline demo runs every stage of the loop on a toy world with scripted agents (a labelled simulation) and writes the same evidence bundle as a real run.

git clone https://github.com/rynitepsd-tech/forkloop.git
cd forkloop/projects/forkloop
python3.11 -m venv .venv && . .venv/bin/activate
pip install -e '.[world]'
forkloop demo-loop --out runs/demo-loop

For real runs: the bundled claims-operations world (OpenEMR 8.3 and a synthetic payer portal) runs in Docker, dozens of copies per machine, or on Solari desktops with VM snapshots. Bring your agent through any OpenAI-compatible endpoint or a small Python class, and your own application through world.yaml and a verifier. A second world, Kanboard, was built only through that public interface; 5 of its 6 recorded failures were repaired.

What is and isn't new

VM snapshots, GUI agent benchmarks, deterministic verification, agent debugging and corrective training all exist. Forkloop's contribution is joining them into one loop that keeps the evidence: every checkpoint, branch, verdict, charge and dataset is recorded, failed and unscored work stays visible, and the learning claim is tested on held-out tasks under a registered protocol.

Built on Solari desktops, Docker and OpenEMR. Synthetic data only; not a HIPAA deployment. Source (MIT) · earlier regression reports.
