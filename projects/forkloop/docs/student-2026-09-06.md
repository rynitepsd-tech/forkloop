Rule applied (written into `runs/logs/bakeoff_chain.sh` before the result was known): the run with the most
`openemr_login` episodes wins, ties broken by the sum of all database rungs, then by the union. (a) and (a)+(b) tie
at 5/5 and one rung; the union wins the tie and is the bake-off configuration: `--nav-macro
--system-prompt-file forkloop/policies/prompts/fara_no_user_v1.md --instruction-note "Credentials for OpenEMR: username
admin, password pass. Click the Username field, type admin, click the Password field, type pass, click Login."`. Both
are convention-level: the note restates what the instruction already says, the prompt removes a rule that has no
meaning without a user and adds the world conventions every teacher prompt carries. The login wall was reading, not
motor: the SFT data will fix it for free (every verified trajectory shows the two-field login), and the first wall
past it is OpenEMR navigation, which only SFT teaches.
